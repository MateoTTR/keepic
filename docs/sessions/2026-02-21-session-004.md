## Issues Found & Fixed

### ESLint config cassé (hérité TASK-003)
`@electron-toolkit/eslint-config-ts` exporte un objet legacy-style (non itérable).
Le spread `...eslintConfigTs` dans `eslint.config.mjs` levait une `TypeError`.

**Fix :** utilisation de `FlatCompat` depuis `@eslint/eslintrc` (dépendance transitive déjà présente)
pour bridger les configs legacy vers le format flat. Mise à jour du script `lint` dans `package.json`
(suppression du flag `--ext` non supporté en flat config).

### `.claude/settings.local.json` toujours tracké par git
Le fichier était indexé avant l'ajout de la règle `.gitignore`.

**Fix :** `git rm --cached .claude/settings.local.json`

### Node.js : version 22 vs 24
Le `.nvmrc` dit `22` mais Node 24.11.1 est actif dans le shell de Claude Code
(shell non-interactif, nvm non sourcé).

**Actions :**
- `nvm alias default 22` → les nouveaux terminaux utiliseront Node 22.22.0
- `better-sqlite3` (addon natif) doit être rebuilé après tout changement de version Node (`npm rebuild better-sqlite3`)
- Le shell de Claude Code utilise Node 24 → bindings rebuilés pour Node 24 pour que les tests passent dans ce contexte

**Point d'attention :** si tu travailles dans ton propre terminal, lancer `nvm use && npm rebuild better-sqlite3` avant de lancer les tests.

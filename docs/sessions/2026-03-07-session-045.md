## Key Decisions

- **node-addon-api over raw N-API**: Cleaner code (~150 LOC vs ~184), native AsyncWorker, exception-safe
- **Two linking modes**: Dynamic (default, for dev/CI with system libheif) and static (`--heif_static=true`, for release builds)
- **HeicDecodePool kept as-is**: AsyncWorker available via `decodeAsync()` but pool with sync `decode()` is proven (12.6x speedup)
- **Build from source in release CI**: No prebuilt binaries to manage, consistent versions across platforms

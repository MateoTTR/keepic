## Key Design Decisions

### State machine
Five states: `idle → waiting → downloading → complete → error`

- **idle**: "Open Google Photos Picker →" button + explanation text. Back button returns to home.
- **waiting**: `createPickerSession()` called → `window.open(pickerUri)` (triggers `setWindowOpenHandler` → `shell.openExternal`) → polling loop every 3s. Spinner + blue info box explaining what to do in the Google Photos tab. "Re-open" button if the tab was closed. Timeout after 100 × 3s = 5 min → error state.
- **downloading**: `startPickerDownload(sessionId)` called → listen to `onPickerDownloadProgress` / `onPickerDownloadComplete`. Progress bar + "X / Y photos" counter + current filename. Cancel button fires `cancelPickerDownload()` and waits for the `complete` event with `status: 'cancelled'` to transition back to `idle`.
- **complete**: Green success banner (N photos downloaded). Amber error list if any files failed. "Analyse →" button (disabled if 0 photos downloaded) calls `onDownloadComplete(result)` → handoff to planning screen.
- **error**: Red error banner. "Try again" → `handleRetry()` resets all state back to idle. "Back" → `onBack()`.

### `window.open` for picker URL
`window.open(pickerUri)` in the renderer triggers the existing `setWindowOpenHandler` in `src/main/index.ts` which calls `shell.openExternal(url)` and returns `{ action: 'deny' }`. No additional IPC handler or preload binding needed.

### Polling
- `POLL_INTERVAL_MS = 3000`, `POLL_MAX = 100`
- Polling is timer-based (`setTimeout` chain) to avoid drift. Each poll schedules the next only after the response arrives.
- Cleared in `clearPolling()`, called on every state transition that exits `waiting`, in `handleBack`, `handleRetry`, and `onDestroy`.

### Listener lifecycle
- `onPickerDownloadProgress` / `onPickerDownloadComplete` registered in `startDownload()`.
- `removePickerDownloadListeners()` called in the `onPickerDownloadComplete` callback itself (before state transition), in `handleBack`, `handleRetry`, and `onDestroy`.

### Download complete status handling
- `completed` → `state = 'complete'`, store `downloadResult`
- `cancelled` → `state = 'idle'`, clear progress (user-initiated cancel)
- `failed` → `state = 'error'`, show first error message

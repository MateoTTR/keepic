# Session 012 — 2026-02-22

## Task
TASK-019 — Implement library statistics view

## Goal
Add a `StatsPanel` component on the home screen that displays a summary of the local library: photo count, total size, date range, and recent import history — all sourced from the existing SQLite index.

## Architecture decisions

### No worker thread
All SQL queries are synchronous aggregates on indexed columns (`COUNT`, `SUM`, `MIN`, `MAX`, `GROUP BY year`). Fast even on large libraries — no worker thread needed.

### `LibraryStatsDeps` interface without parameter
The `LibraryStatsDeps` interface (containing an injectable `now` clock) is defined for future extensibility but not included as a function parameter in the current implementation. The ESLint rule `@typescript-eslint/no-unused-vars` flags parameters that come after the last used one (`db`), making `_deps` impossible to include without a workaround. Since `now()` is not used in any query, the interface is documentation only.

### `onMount` in HomeScreen
Stats are fetched in `HomeScreen.svelte`'s `onMount` rather than in `App.svelte`, keeping the stats concern local to the screen that displays them.

### `each` key in StatsPanel
`svelte/require-each-key` requires a key expression. Used `imp.finishedAt + imp.source` as a composite key (each import job has a unique finished_at timestamp per source within the last 5).

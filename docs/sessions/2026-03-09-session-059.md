## Changes

### 1. LazyGroup component (`src/renderer/src/components/LazyGroup.svelte`)

New Svelte component that wraps content and uses `IntersectionObserver` to track
viewport visibility. When a group scrolls off-screen, its content is replaced by
a lightweight placeholder `<div>` with the last measured height. This bounds the
active DOM node count regardless of how many groups are loaded.

- `rootMargin: '200px'` — groups are mounted 200px before entering the viewport
- `use:onContentMount` action measures the real height on first render
- Once measured, the placeholder uses the exact measured height (no layout jumps)

### 2. DeduplicationScreen path display

Replaced the single truncated `photo.path` line with:
- **Filename** (`break-all`, `font-medium`, `text-gray-900`) — always fully visible
- **Folder path** below in smaller lighter text (`text-[10px]`, `text-gray-400`, `truncate`)

The filename is the most useful information for identifying a duplicate; the folder
is secondary context.

### 3. Integration

Each duplicate group in the `{#each}` loop is now wrapped with `<LazyGroup>`.
Combined with the existing pagination (20 groups per page), this means:
- Only groups in/near the viewport have their thumbnails mounted
- "Show more" still works to load additional pages
- DOM node count stays bounded even with hundreds of groups loaded

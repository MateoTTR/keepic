# Session 046 — 2026-03-07

## Task

**TASK-050 follow-up** — Fix cross-platform CI for `@keepic/heif-decode` static addon builds

## Summary

Validated and fixed the `build-heif-addon.yml` workflow across 3 platforms (linux-x64, darwin-arm64, win32-x64). Resolved 8 distinct build issues, mostly Windows/MSVC-specific. Added a HEIC decode smoke test to CI. Removed darwin-x64 target (no free GitHub runner available).

## Issues Fixed

| # | Platform | Problem | Fix |
|---|----------|---------|-----|
| 1 | macOS/Linux | CMake 4.x rejects `cmake_minimum_required < 3.5` | `-DCMAKE_POLICY_VERSION_MINIMUM=3.5` |
| 2 | Windows | Doxygen build fails (Graphviz not installed) | `-DCMAKE_DISABLE_FIND_PACKAGE_Doxygen=TRUE` |
| 3 | Windows | libheif test executables fail to link (static de265) | `-DBUILD_TESTING=OFF` |
| 4 | Windows | Static lib name mismatch (`de265.lib` → `libde265.lib`) | Fix `binding.gyp` library path |
| 5 | Windows | `__imp_heif_*` unresolved (dllimport) | `LIBHEIF_STATIC_BUILD` define in `binding.gyp` |
| 6 | Windows | CRT mismatch `/MD` vs `/MT` | `-DCMAKE_MSVC_RUNTIME_LIBRARY=MultiThreaded` |
| 7 | Windows | `__imp_de265_*` unresolved in `heif.lib` | `-DLIBDE265_STATIC_BUILD` via `CMAKE_C/CXX_FLAGS` when building libheif |
| 8 | Windows | CMP0091 policy defaulting to OLD | `-DCMAKE_POLICY_DEFAULT_CMP0091=NEW` |
| 9 | All | No runtime validation of built addon | Added smoke test step (decode 702KB sample HEIC) |
| 10 | macOS | `macos-13` runner no longer available | Removed darwin-x64 from matrix (Intel Mac no longer supported) |

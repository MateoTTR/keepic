## TASK-032 — Implement Picker API session backend (PR #30)

### Goal

Implement the main-process module for managing Google Photos Picker API sessions:
create, poll, and list media items.

### Changes

**New files**:
- `src/main/google-photos-picker.ts` — Three exported functions:
  - `createPickerSession(accessToken, deps?)` — POST to create a session, returns `{ id, pickerUri }`
  - `pollPickerSession(sessionId, accessToken, deps?)` — GET session status, returns `{ mediaItemsSet }`
  - `listPickerMediaItems(sessionId, accessToken, pageToken?, deps?)` — GET paginated media items
  - All use injectable `fetch` dep for testing, 401 → "Token expired" error
  - Maps Picker API `mediaFile` structure to `PickerMediaItem` type
- `tests/main/google-photos-picker.test.ts` — 15 tests covering all functions, error cases, pagination

**Updated files**:
- `src/shared/types/index.ts` — Added `PickerMediaItem` and `PickerSession` interfaces
- `src/main/ipc/google-photos-handlers.ts` — Added `handleCreatePickerSession` and
  `handlePollPickerSession` handlers with `getValidAccessToken` integration
- `src/main/index.ts` — Registered `google:create-picker-session` and
  `google:poll-picker-session` IPC channels
- `src/preload/index.ts` + `index.d.ts` — Added `createPickerSession` and
  `pollPickerSession` bindings
- `tests/main/ipc/google-photos-handlers.test.ts` — 10 new tests for picker handlers

### Tests

303 tests pass with 100% coverage.

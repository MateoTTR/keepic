**Architecture de test :**

- `ExifLoader` et `PhashComputer` injectables → mocks dans les tests indexer (pas de vraies images nécessaires pour la majorité des tests).
- Tests `chmodSync` pour couvrir les catch blocks FS inaccessibles.
- Test sans options pour couvrir les branches `?? defaultExifLoader` / `?? defaultPhashComputer`.
- `phash.ts` lignes `?? 0` ignorées via `/* v8 ignore next 2 */` (impossible de provoquer width/height undefined avec sharp sur des images valides).

**Problèmes résolus pendant l'implémentation :**

| Problème | Cause | Solution |
|---|---|---|
| `parseExifDateString` ne rejette pas month=13 | `new Date(2023, 12, 1)` wrap silencieux | Ajout `d.getMonth() !== month - 1` |
| `dctHash` hash attendu incorrect | DC term > mean → bit 0 = 1 même pour image uniforme | Test all-black (DC=0) + idempotence |
| pHash identique pour rouge/bleu | Même luminance grayscale | Remplacement par gradient vs damier |
| Re-index rate cause mtime identique dans même milliseconde | `writeFileSync` deux fois rapides | `utimesSync` avec `Date.now() + 2000` |
| TypeScript `Dirent<NonSharedBuffer>` | `ReturnType<typeof readdirSync>` ambiguë | Type explicite `Dirent<string>[]` |
| `err` unknown dans Worker error handler | @types/node strict | Cast `(err: Error)` |

# Session 056 — 2026-03-08

## Task

**TASK-064-fix** — Improve pHash deduplication robustness

## Summary

Implemented three complementary improvements to fix false positives and maintain true duplicate detection:

1. **Median threshold** for DCT pHash: replaces mean with median for AC coefficient thresholding, eliminating "attractor" hashes (e.g. `8080808080808080`) that caused false positives. Same approach as Meta's PDQ perceptual hash.

2. **dHash (difference hash)**: new 64-bit hash encoding horizontal brightness gradients, orthogonal to DCT frequency analysis. Both hashes computed from the same 32×32 greyscale buffer (single image decode).

3. **Dual-hash matching**: duplicate detection now requires both pHash AND dHash Hamming distance ≤ 4, drastically reducing false positives while maintaining cross-format duplicate detection (HEIC↔JPEG).

Database migration 4→5 adds `dhash` column and invalidates existing pHash values (re-index required after upgrade).

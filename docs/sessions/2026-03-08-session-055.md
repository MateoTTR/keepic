## Task

**TASK-063-feat** — Enrich import history with source and date range of imported media

## Summary

Added `job_id` foreign key to the `photos` table to link each imported photo to its import job. The stats query now JOINs photos on `job_id` to compute `MIN/MAX(date_taken)` per job, exposing `oldestMediaDate` and `newestMediaDate` in `LibraryStats.recentImports`. The StatsPanel UI displays the media date range (e.g. "Jan 2024 – Mar 2025") next to each import entry.

## Décisions techniques

### Migration React → Svelte 5

- `@sveltejs/vite-plugin-svelte@4.x` utilisé (compatible Vite 5 de electron-vite 2.3.0)
- `@sveltejs/vite-plugin-svelte@6.x` (dernière version) requiert Vite 6+ → incompatible

### Tailwind CSS v4 via PostCSS

- `@tailwindcss/vite` requiert Vite 6+ → incompatible avec electron-vite 2.3.0
- Solution : `@tailwindcss/postcss` + `postcss.config.cjs` → fonctionne avec Vite 5
- `@import 'tailwindcss'` dans `app.css` suffit (pas de `tailwind.config.js` nécessaire en v4)

### IPC simplifié

Le preload `import.plan` passe uniquement `{ sourcePath }` — le main process récupère libraryPath/dbPath/config en interne depuis `configManager`. Idem pour `import.execute` qui ne reçoit que `{ plan }`.

### ReviewScreen — gestion des doublons

- Copie locale `localPlan` (Svelte `$state`) pour permettre la mutation `duplicate → ready`
- Tri $derived : ready/collision → duplicate → error
- Expansion inline par `expandedPath: string | null` (un seul ouvert à la fois)
- "Import anyway" : mute le statut localement, referme l'expansion
- "Import N files" passe le `localPlan` modifié au parent via `onImport()`

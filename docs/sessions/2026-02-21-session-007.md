### TASK-009 — HEIC handling (Live Photo detection + conversion)

**Fichiers créés :**

| Fichier | Rôle |
|---|---|
| `docs/tasks/TASK-009-heic-handling.md` | Spec de la tâche |
| `src/main/heic.ts` | Module HEIC : détection Live Photo + conversion HEIC→JPEG |
| `tests/main/heic.test.ts` | 16 tests — 100% coverage |

**API du module `src/main/heic.ts` :**

| Export | Type | Description |
|---|---|---|
| `getHeicCandidatePaths(movPath)` | fonction pure | Retourne les chemins `.heic` et `.heif` pour un `.MOV` |
| `ExistsChecker` | type injectable | `(path: string) => boolean` |
| `isLivePhotoMov(movPath, checkExists?)` | fonction | `true` si le `.MOV` est un companion Live Photo |
| `HeicConverter` | type injectable | `(src, dest, quality) => Promise<void>` |
| `defaultHeicConverter` | implémentation | `sharp(src).jpeg({ quality }).withMetadata().toFile(dest)` |
| `convertHeicToJpeg(src, dest, quality, converter?)` | wrapper injectable | Convertit HEIC→JPEG, EXIF préservé |

**Décisions prises :**
- Pattern injectable identique à `ExifLoader` / `PhashComputer` (cohérence codebase)
- `isLivePhotoMov` vérifie `.heic` et `.heif` (minuscule) — suffisant sur Windows/macOS (filesystems case-insensitive)
- Qualité JPEG : configurable via `AppConfig.heicConversion.jpegQuality` (défaut 90) — l'import pipeline passera la valeur
- Détection codec Windows (Q3) : reportée hors scope TASK-009

**Problème résolu :**

| Problème | Cause | Solution |
|---|---|---|
| Test quality "expected 0 to be greater than 0" | `sharp.metadata().size` non disponible pour les fichiers (Stream/Buffer only) | Remplacé par `statSync(path).size` |

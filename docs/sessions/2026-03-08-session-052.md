# Session 052 — 2026-03-08

## Goals

- Investigate GitHub issue #66: KeePic v0.3.4 does not run on macOS + blurry icon
- Fix the icon issue
- Provide workarounds for the unsigned app issue

## Diagnostic

Issue #66 reported two problems:

1. **App won't launch on macOS** — initial hypothesis was corrupted ICNS file, but investigation revealed the real cause is **macOS Gatekeeper** blocking the unsigned app. The typical error message ("app is damaged and can't be opened") is misleading — the binary is not actually corrupted. Without an Apple Developer certificate ($99/year), the app cannot be code-signed or notarized.

2. **Blurry icon** — `resources/icon.icns` was a 16x16 PNG file (973 bytes) instead of a proper macOS ICNS icon bundle. Introduced in commit `774a882` (TASK-055-feat) when the icon was first added.

## Completed

### Issue #66 — Workarounds for unsigned macOS app

Posted a comment on issue #66 with three workarounds:
- Right-click > Open (simplest, one-time)
- System Settings > Privacy & Security > Open Anyway
- Terminal: `xattr -cr /Applications/KeePic.app`

No Apple Developer certificate planned — app will remain unsigned.

### TASK-056-fix — Fix macOS icon (PR #67)

- Regenerated `resources/icon.icns` as a proper macOS ICNS bundle (387 KB, `ic07` type) using `electron-icon-builder` from the 512x512 PNG source
- Also regenerated `resources/icon.ico` for consistency
- Created task description file and updated backlog

## Goals

- Fix MOV files incorrectly detected as Live Photo companions (TASK-060)

## Completed

### TASK-060-fix — Fix MOV Live Photo detection (PR #71)

- Removed `.mov` from `LIVE_PHOTO_VIDEO_EXTENSIONS` in `src/main/heic.ts`
- Only `.mp4` is now considered a Live Photo video format
- MOV files with a same-name photo sibling are indexed as standalone videos
- Updated specs §2.7 to clarify Live Photo detection rules
- Updated tests in `heic.test.ts`, `indexer.test.ts`, `importer.test.ts`

### TASK-061-fix — HEIC-as-JPEG magic bytes detection (PR #71)

- 4,841 `.HEIC` files in the real library were actually JPEG (magic bytes `FF D8 FF`), likely converted by Synology Photos or iCloud sync
- `libheif` failed with "No 'ftyp' box" on these files
- Added `isJpegBuffer()` to `src/main/heic.ts` as a shared utility
- `createUniversalPhashComputer`: checks magic bytes before HEIC decode — routes JPEG-in-HEIC through sharp pHash
- `createHeicConverter`: checks magic bytes before HEIC decode — re-encodes JPEG-in-HEIC via sharp directly
- Removed local `isJpegBuffer()` from `google-photos-picker-downloader.ts`, now imports from `heic.ts`
- 7 new tests added

### PR #71 — merged (squash into `develop`)

Both fixes shipped in a single PR targeting `develop`.

# Session 057 — 2026-03-09

## Focus

**TASK-065-perf** — Optimize dedup scan with Multi-Index Hashing + worker thread

## Context

User reported that KeePic freezes on Windows after clicking "Scan for duplicates"
with a library of ~10,000 photos. Investigation revealed that TASK-064 (pHash
robustness) replaced the instant SQL `GROUP BY phash` with an O(n²) JavaScript
nested loop for Hamming distance matching, running synchronously on the main thread.

## Changes

### Multi-Index Hashing (`src/main/multi-index-hash.ts`) — NEW

- `MultiIndexHash` class: splits 64-bit hex hashes into 5 chunks (3+3+3+3+4 hex chars),
  indexes each chunk in a separate `Map<string, number[]>`
- Pigeonhole principle: if two hashes differ by ≤ 4 bits, at least one of 5 chunks
  is identical → candidate lookup in O(1) per chunk instead of O(n)
- `isDualHashMatch()` helper: dual-hash verification (pHash + dHash) extracted for reuse

### Dedup scan handler (`src/main/ipc/dedup-scan-handler.ts`)

- `handleScanDuplicates()` now returns `{ photoRows, videoGroups }` — SQL queries only
- `findDuplicateGroups()` exported: Multi-Index build + Union-Find grouping with
  optional `onProgress` callback
- Video dedup unchanged (SQL `GROUP BY filename, file_size` — already instant)

### Worker thread (`src/workers/dedup-scanner.worker.ts`) — NEW

- Receives photo rows via `postMessage`, runs `findDuplicateGroups()` in background
- Sends throttled progress events (every 5%) and final `complete` message
- Registered in `electron.vite.config.ts` rollup inputs

### IPC wiring (`src/main/index.ts`)

- `library:scan-duplicates` handler now spawns worker, returns `{ started: true }` immediately
- New channels: `library:dedup-progress`, `library:dedup-complete`
- Worker error handling → sends `{ groups: [], error }` to renderer

### Preload + UI

- `src/preload/index.ts` + `index.d.ts`: `onDedupProgress`, `onDedupComplete`,
  `removeDedupListeners` callbacks
- `DeduplicationScreen.svelte`: progress bar with percentage and photo count,
  uses `onMount`/`onDestroy` pattern (not `await`)

### Importer (`src/main/importer.ts`)

- Library hash lookup in Phase 2 now uses `MultiIndexHash` instead of linear scan

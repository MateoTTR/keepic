## Completed

### TASK-054-fix — Fix Google Picker video download (PR #63, merged)

- **Video download suffix**: Changed `=d` to `=dv` for items with `mimeType.startsWith('video/')` in `downloadMediaItem`. This ensures full video files are downloaded instead of ~200-300 kB thumbnails.
- **creationTime extraction**: Updated `listPickerMediaItems` in `google-photos-picker.ts` to extract `createTime` from the Picker API response and populate `PickerMediaItem.mediaMetadata.creationTime`.
- **mtime from creationTime**: After writing a downloaded file, set its mtime to the `creationTime` value (when available and valid) using `utimesSync`. This ensures correct date sorting even for videos that lack EXIF metadata.
- **Injectable `setFileTimes`**: Added `setFileTimes` to `DownloaderDeps` for testability.
- 7 new tests added. 527 tests total, 100% coverage.

### TASK-055-feat — Add application icon (PR #64, merged)

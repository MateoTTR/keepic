### TASK-038 — Fix Picker API list media items URL

**Root cause**: `listPickerMediaItems` in `src/main/google-photos-picker.ts` constructed:
```
GET /v1/sessions/{sessionId}/mediaItems?pageSize=100
```
The correct Picker API endpoint is:
```
GET /v1/mediaItems?sessionId={sessionId}&pageSize=100
```

**Fix** (2 lines in `listPickerMediaItems`):
- Added `sessionId` to the `URLSearchParams` object instead of embedding it in the path
- Changed the URL from `/sessions/${sessionId}/mediaItems?...` to `/mediaItems?...`

**Tests**: Updated URL assertions in `tests/main/google-photos-picker.test.ts` to reflect the corrected endpoint structure (sessionId as query param, pageSize as query param, pageToken appended when present).

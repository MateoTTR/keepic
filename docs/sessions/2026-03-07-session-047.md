# Session 047 — 2026-03-07

## Task

**Release v0.3.1 / v0.3.2** — Validate release pipeline with native HEIC addon + fix runtime issues

## Summary

Released v0.3.1 and v0.3.2. Fixed two release-blocking issues discovered during the process:

1. **release.yml CI failure**: `npm ci` triggers the addon install script (`node-gyp-build`) before `build-deps.sh` has compiled libde265/libheif, causing `heif_cxx.h` not found. Fix: `npm ci --ignore-scripts`, then build deps, then explicit `node-gyp rebuild --heif_static=true`.

2. **HEIC worker path error in production**: `heic-pool.ts` uses `__dirname` to locate `heic-decode.worker.js`, but Rollup places `heic-pool.ts` in a shared chunk (`out/main/chunks/`), not `out/main/workers/`. Fix: resolve via `join(__dirname, '..', 'workers', 'heic-decode.worker.js')`.

Manual testing of v0.3.2 on Windows confirmed:
- Re-indexing works and is ~11x faster (33s vs 6min with WASM)
- 85 HEIC files fail with "Too many auxiliary image references" — Apple HDR photos (iOS 18+), libheif 1.17.6 limitation → TASK-051
- EPERM on picker-staging cleanup (Windows file lock) → TASK-052
- Feature request: differentiate photos vs videos in stats → TASK-053

## TASK-031 — Remove deprecated Library API code (PR #29)

### Goal

Clean removal of all code implementing the deprecated Google Photos Library API
(`photoslibrary.readonly` scope, `mediaItems:search` endpoint). Prerequisite
cleanup before building the new Picker API integration.

### Changes

**Deleted files**:
- `src/main/google-photos-downloader.ts` — Library API fetch/download logic
- `src/workers/google-photos-download.worker.ts` — download worker thread
- `tests/main/google-photos-downloader.test.ts` — associated tests (~690 lines)

**Updated files**:
- `src/main/google-auth.ts` — `GOOGLE_SCOPE` updated:
  `photoslibrary.readonly` → `photospicker.mediaitems.readonly`.
  Scope verification error messages updated in `startOAuthFlow` and
  `getValidAccessToken`.
- `src/main/ipc/google-photos-handlers.ts` — `handleStartDownload` and
  `handleCancelDownload` removed. Only `handleGetLastDownloadDate` and
  `handleCleanupDownloadDir` remain.
- `src/main/index.ts` — Removed import and registration of deleted handlers,
  removed `googleDownloadWorkerRef` and `googleDownloadWorkerPath`.
- `src/preload/index.ts` + `index.d.ts` — Removed `startDownload`,
  `cancelDownload`, `onDownloadProgress`, `onDownloadComplete` bindings.
- `electron.vite.config.ts` — Removed `workers/google-photos-download.worker`
  Rollup entry.
- `src/renderer/src/screens/GoogleDownloadScreen.svelte` — Replaced with
  placeholder ("Google Photos import is being upgraded" + amber warning banner).
- `src/shared/types/index.ts` — `GoogleDownloadProgress` interface removed
  (no longer referenced). `GoogleDownloadResult` kept (still used in App.svelte).
- All test files updated to reference `photospicker.mediaitems.readonly` scope.

### Tests

278 tests pass with 100% coverage (down from 335 — difference is the deleted
Library API tests).
